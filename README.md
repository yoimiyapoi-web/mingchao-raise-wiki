# 鸣潮养成 Wiki

粉丝向的《鸣潮》角色养成资料站:角色图鉴、养成材料表、养成计算器、武器与素材图鉴。

数据与图片全部来自[库街区·鸣潮 Wiki](https://wiki.kurobbs.com/mc/home)的公开接口,构建时抓取为静态快照,网页不依赖官方接口在线。内容版权归库洛游戏所有,本站仅供学习交流,非官方站点。

## 功能

- 首页:数据概览、最新共鸣者、功能入口
- 角色库:62 位共鸣者,按属性 / 稀有度 / 武器 / 版本筛选,支持名称搜索
- 角色详情:基础资料、属性表、技能说明、六阶突破材料、技能升级材料(含分支强化)、共鸣链、攻略与档案
- 养成计算器:选择角色与当前/目标等级、各技能分支等级,自动汇总材料与贝币,支持复制清单、本地保存计划
- 武器图鉴(120 把)与素材图鉴(290 种)

## 本地运行

```bash
npm install          # 安装依赖
npm run refresh-data # 拉取官方接口数据(可选,仓库已含数据快照)
npm run dev          # 开发模式:自动重建 + 本地服务器 http://127.0.0.1:4173
npm run build        # 生产构建,产物在 dist/
npm run preview      # 预览构建产物
```

> 说明:本项目使用 Rollup 构建(Rollup 为纯 JS 实现)。`vite.config.js` 与 Vite 依赖仅为保留文件,未参与构建。

## 数据管线

`scripts/fetch-data.mjs` 调用库街区公开接口:

- 目录与列表:`POST /wiki/core/catalogue/item/getPage`(共鸣者 1105、武器 1106、素材 1218、资源 1161)
- 角色详情:`POST /wiki/core/catalogue/item/getEntryDetail`(词条 entryId)

输出到 `src/data/`:

- `characters/index.json`:角色卡(名字、星级、属性、武器、版本、定位、立绘)
- `characters/<entryId>.json`:单角色详情(基础资料、属性、技能、突破/技能材料、共鸣链、攻略、档案),按需加载
- `weapons.json`、`materials.json`、`meta.json`
- `src/lib/detail-loaders.js`:自动生成的按需加载映射

`npm run refresh-data` 可随时重新抓取,同步官方最新内容。

## 计算器口径

- 角色等级只在门槛点(20/40/50/60/70/80)消耗突破材料:从当前等级升到目标等级,需要「门槛 ≥ 当前等级且 < 目标等级」的各阶段突破材料;1→20 无需突破材料
- 技能升级:数据表 LV.2~LV.10 代表升到对应等级的消耗,计算器按当前+1 到目标逐档汇总
- 分支强化:官方词条中的一次性强化材料,按「被升级的分支」各计一次,可在计算器中关闭
- 官方词条偶有错别字(如「碑趺古钟钟」),抓取时已归一化

## 已知说明
